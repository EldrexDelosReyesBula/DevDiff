# DevDiff IDE Integration (v1.5.0)

> [!IMPORTANT]
> DevDiff operates **100% natively inside your IDE**. Web browser playground workflows have been deprecated. All DevDiff operations (diff analysis, persistent memory, conversational Q&A, automated versioning, SKILL.md management, and commit guards) are performed directly inside your IDE environment (VS Code extension, MCP server, and integrated terminal CLI).

Please see the [IDE Integration Guide](/features/ide-integration) for full details on VS Code, Cursor, Windsurf, and CLI setup.
