<p style="color: #888; font-size: 0.9em;">July 7, 2026 · Eldrex Delos Reyes Bula</p>

Every download represents a developer who chose privacy-first tooling, local-first AI, and ownership over their development workflow. That's a milestone worth celebrating.

## 📈 What the Data Tells Us

### The ecosystem is being adopted together

The three most-downloaded packages—`@eldrex/gateway` (744), `@eldrex/personas` (724), and `@eldrex/core` (718)—have remarkably similar download counts.

That suggests developers are adopting the DevDiff ecosystem as intended rather than installing isolated packages. Shared dependencies and integrated workflows naturally result in closely aligned download numbers across the core libraries.

### Integrations are gaining traction

Both `@eldrex/vite` and `@eldrex/openclaw` sit at **698 downloads**, demonstrating that developers are integrating DevDiff directly into their build pipelines and automation workflows instead of using it only as a standalone CLI.

### The CLI remains a primary entry point

With **586 downloads**, `@eldrex/cli` continues to be one of the primary ways developers discover DevDiff. The familiar `npx devdiff init` and `devdiff generate` workflow remains the quickest way to get started.

### Open VSX takes off in 24 hours

Published just yesterday on **July 6, 2026**, the DevDiff extension on Open VSX has already surpassed **230 downloads** in its first 24 hours. This rapid adoption highlights strong demand from developers using open-source, vendor-neutral extension registries—particularly those on VS Code forks, Eclipse Theia-based editors, and other platforms that rely on Open VSX.

The speed of this growth also signals that the privacy-first, local-first philosophy behind DevDiff resonates deeply with the open-source community that Open VSX serves.

### The VS Code Marketplace is just getting started

The npm package for the VS Code extension has been downloaded **80 times**, while the extension currently has **1 install** from the VS Code Marketplace.

These numbers measure different things:

- **npm downloads** count installs of the published package, including development environments and automated workflows.
- **Marketplace installs** count users who install the extension directly through Visual Studio Code.

Since the Marketplace release is new, we expect Marketplace adoption to grow over time alongside the Open VSX momentum.

### The dashboard has its own audience

At **546 downloads**, `@eldrex/dashboard` shows continued interest in a graphical experience alongside the command-line tooling.

## 🔒 What We Shipped

The v1.0.3 Hardening Release introduced several major improvements:

- **Extension Guard** — Workspace-bound sandboxing for the VS Code extension.
- **Network Guard** — Network access disabled by default, with cloud AI providers remaining opt-in.
- **Multi-Agent Consensus** — Multiple specialized AI agents review every generated changelog.
- **Cross-Platform CI** — Automated testing across Windows, macOS, and Linux.
- **Expanded Documentation** — Over 60 pages covering setup, integrations, and deployment.

The v1.0.6 release brought DevDiff to **Open VSX**, making the extension available to developers on open-source editor platforms including VS Codium, Eclipse Theia, Gitpod, and more.
