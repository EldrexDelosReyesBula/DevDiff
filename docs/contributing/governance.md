# Open Source Governance & Maintainer Model

DevDiff is an open-source project maintained by **Eldrex Delos Reyes Bula** alongside community contributors. We adhere to a transparent, meritocratic governance model designed to keep the project privacy-first, secure, and developer-owned.

---

## Governance Principles

1. **Privacy & Security First**: Core security guardrails (`NetworkGuard`, `RedactionEngineV2`, `InjectionGuardV2`) cannot be compromised or disabled by default.
2. **Local-First Default**: Local execution (Ollama, WebGPU, ONNX) is always prioritized over cloud provider requirements.
3. **Open Specifications**: MCP extensions, plugin SDK APIs, and SKILL.md formats are kept fully open and documented.

---

## Roles & Decision Process

- **Maintainer**: Eldrex Delos Reyes Bula (`@EldrexDelosReyesBula`) — Final authority on architecture, breaking changes, and releases.
- **Contributors**: Anyone who submits pull requests, files issues, or improves documentation.
- **Proposal Process**: Major architectural changes or additions to `@eldrex/core` require a proposal issue opened on GitHub Discussions prior to PR submission.
